# Official logos for AerynOS

## Variants

1. Dark theme: The primary logo for AerynOS
2. Light theme: An alternative logo with better orange contract on light backgrounds

Both the Light and Dark theme have 128px, 192px and 1000px variants of PNGs all with transparent backgrounds depending on your requirements for image size / clarity.

### Legacy

The legacy logos have been preserved in "Legacy" folders for reference.
